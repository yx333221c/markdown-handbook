# 速查表

> English: [en/cheatsheet.md](../en/cheatsheet.md)

写的时候记不住某个符号怎么拼，翻这一页就够。下面的例子都放在围栏代码块里，因为它们正是要展示的源码；正文里提到单个符号才用行间代码。想弄清某条规则为什么这么定，去看 [commonmark.md](../../03-spec/zh/commonmark.md) 和 [gfm.md](../../03-spec/zh/gfm.md)。

## 标题

`#` 开头，后面必须跟空格，1 到 6 个对应 `<h1>` 到 `<h6>`。行尾可以再补一串 `#` 收尾，解析器会丢掉它。`#hashtag` 不算标题。

```markdown
# 一级
### 三级
## 二级 ##
#hashtag
```

另一种写法叫 Setext，拿 `=` 或 `-` 垫在文字下面：

```markdown
大标题
======

小标题
------
```

`=` 出 `<h1>`，`-` 出 `<h2>`。它和分隔线撞车，`---` 到底算标题下划线还是分隔线，要看前面有没有空行。我一般只用 `#`。

## 段落与换行

空一行就分段。行尾只敲一个回车，渲染时通常并成一个空格，这叫软换行。想要硬换行，行尾补两个空格，或者放一个 `\`：

```markdown
第一行  
第二行

第一行\
第二行
```

两种都出 `<br>`。编辑器复制粘贴时容易吃掉尾部空格，所以我更常用 `\` 那种。

## 强调

`*x*` 或 `_x_` 出 `<em>`，`**x**` 或 `__x__` 出 `<strong>`。

```markdown
*斜体*  _也是斜体_
**粗体**  __也是粗体__
```

写 `snake_case_name` 不会变斜体，CommonMark 规定词内下划线不产生强调。写完 `*` 忘了闭合，后面整段跟着变斜体，这是真会碰上的故障。要显示字面星号用 `\*`，反斜杠转义只对 ASCII 标点有效。

## 列表

`-`、`*`、`+` 都起无序列表，数字加个点起有序列表。缩进就嵌套，前面留空行更稳：

```markdown
- 苹果
- 梨
  - 鸭梨
- 香蕉

1. 先写
2. 再写
```

同一份文档里换着用 `-` 和 `*` 没问题，但混着看花眼，我固定用 `-`。子列表缩进几个空格、列表项什么时候包 `<p>`，Gruber 的原说明没给答案，GFM 规范 1.3 节专门列了这类没答的问题。

## 引用

`>` 开头是块引用，连着几行都写 `>` 就并成一段，嵌套用 `>>`：

```markdown
> 引一段话，
> 接着第二行。
>
> > 再嵌一层。
```

GFM 里 `> ` 后面接 `- [ ]` 能做出任务列表，见扩展那节。

## 代码

短的一段用反引号包住，像 `README.md`。成段有两种写法。围栏代码块用至少三个反引号或波浪号，开闭得是同一种字符，闭合的那串不能比开头短：

````markdown
```python
print("hi")
```
````

上面这段源码要拿四个反引号当外层才装得下。信息字符串第一个词通常当语言名，转出的 HTML 里加 `language-` 前缀的 class，比如 `language-python`。缩进代码块则是每行前面敲四个空格，前面得空一行，也不能打断段落：

```markdown
    四个空格起头
    第二行照旧
```

## 链接、图片、自动链接

链接三种写法，图片是在最前面补 `!`：

```markdown
[文字](https://example.com "标题")
[文字][id]
<https://example.com>
![替代文字](pic.png)

[id]: https://example.com
```

`[id]: url` 那行叫链接引用定义，放哪儿都行，不渲染成可见内容。多个同名定义谁优先，原说明没写死。图片方括号里是替代文字（`alt`），别空着。

## 分隔线

三个及以上的 `-`、`*`、`_` 单独成行就是主题分隔线，中间允许夹空格：

```markdown
---
***
- - -
```

行首缩进四个空格，这行就归缩进代码块了。它和 Setext 的 `-` 下划线只差一个空行，写的时候留神。

## GFM 扩展

下面几项不在 Gruber 原始语法里，是 GitHub 加的，在 GFM 规范目录里都标了 `(extension)`。CommonMark 解析器不认它们。

```markdown
| 列 A | 列 B |
| --- | --- |
| 一 | 二 |

- [x] 已做
- [ ] 待做

~~删掉这段~~

www.example.com
```

表格里的 `|` 是结构符号，要在单元格里显示字面管道符得写 `\|`。GFM 转完 HTML 之后还会做一轮安全过滤（sanitization），并禁止某些原始 HTML。表格、任务列表、删除线、扩展自动链接、disallowed raw HTML，这五项就是 GFM 相对 CommonMark 的全部扩展。想确认某个站点支不支持，把同一段源码丢进 Babelmark 比一遍最快。

## 一组源码 → HTML 对照

把标题、强调、链接凑一起：

```markdown
## 发布说明

先看 **CHANGELOG**，再看 [规范](https://spec.commonmark.org/)。
```

转出来：

```html
<h2>发布说明</h2>
<p>先看 <strong>CHANGELOG</strong>，再看 <a href="https://spec.commonmark.org/">规范</a>。</p>
```

`##` 变成 `<h2>`，两行之间没空行就并成一段。块级元素看 [blocks.md](../../02-syntax/zh/blocks.md)，行内标记看 [inline.md](../../02-syntax/zh/inline.md)，围栏的规矩在 [code.md](../../02-syntax/zh/code.md)。
