# Timeline

> 中文: [zh/timeline.md](../zh/timeline.md)

This table keeps only events with a date you can look up: a release, a post, a version stamp. Where a day is known I give the full date; where only a year or month is recorded, I leave it at that. The rows run in time order, not by how much each one mattered.

| Date | What happened |
| --- | --- |
| 2002 | Aaron Swartz's `atx`, which marks heading levels with a leading `#` |
| 2004 | John Gruber and Aaron Swartz build Markdown; Gruber writes the Perl converter `Markdown.pl` |
| 2004-12-17 | `Markdown 1.0.1` ships; `Markdown.pl` is updated for the last time and never touched again |
| 2012-10-25 | Jeff Atwood publishes "The Future of Markdown", proposing a shared spec and test suite |
| 2014 | John MacFarlane, David Greenspan, Vicent Marti and others start the project that becomes CommonMark |
| 2017-03-24 | GitHub publishes "A formal spec for GitHub Flavored Markdown", announcing the GFM spec built on CommonMark |
| 2019-04-06 | The GFM spec page is stamped `0.29-gfm` |
| 2021-06-19 | CommonMark `0.30` |

The gap between 2004 and 2014 doesn't mean nothing happened. Implementations forked, people ran documents through Babelmark to compare output, and questions like how many spaces indent a sublist or whether a block quote needs a blank line before it kept coming up. That work has no single release with a firm date, so I didn't invent a row for it. For the thread through those years, see [From Gruber to CommonMark](from-gruber-to-commonmark.md); for the first years, [Where Markdown Came From](how-it-started.md).
