# 时间线

> English: [en/timeline.md](../en/timeline.md)

这张表只收能查到明确日期的节点：一次发布、一篇帖子、一次版本标注。查得到日的写全，只查到年份或月份的就不硬凑成某一天。顺序按时间排，不看重要性。

| 日期 | 事情 |
| --- | --- |
| 2002 | Aaron Swartz 的 `atx`，用行首 `#` 标标题层级 |
| 2004 | John Gruber 与 Aaron Swartz 做出 Markdown；Gruber 写下 Perl 转换器 `Markdown.pl` |
| 2004-12-17 | `Markdown 1.0.1` 发布；`Markdown.pl` 最后一次更新，此后没再动过 |
| 2012-10-25 | Jeff Atwood 发《The Future of Markdown》，提议一起定规范和测试集 |
| 2014 | John MacFarlane、David Greenspan、Vicent Marti 等人启动后来叫 CommonMark 的项目 |
| 2017-03-24 | GitHub 发博客《A formal spec for GitHub Flavored Markdown》，公布基于 CommonMark 的 GFM 正式规范 |
| 2019-04-06 | GFM 规范页面标注 `0.29-gfm` |
| 2021-06-19 | CommonMark `0.30` |

2004 到 2014 中间空着，不是那十年没事发生。实现在分叉，Babelmark 被拿来比对输出，缩进几个空格、块引用前要不要空行这类问题反复被讨论。这些是过程，没有单一、能查到确切日期的发布节点，我没给它们编一行。想看这段脉络，翻 [从 Gruber 到 CommonMark](from-gruber-to-commonmark.md)；开头那几年见 [Markdown 是怎么来的](how-it-started.md)。
